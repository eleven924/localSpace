# LocalSpace 介绍与使用文档

本文档基于当前项目实现整理，覆盖软件核心功能、推荐使用流程以及设置页内置文档入口说明。

## 1. 软件核心功能

LocalSpace 是一款本地文件索引与整理工具，主要围绕“把本地资料整理成可搜索、可回看、可持续维护的资料库”来设计。

当前项目已经实现的核心功能包括：

1. 文件导入与归档
   用户可以从本地选择文件导入系统，并为文件补充名称、描述、标签与关键词。
2. 统一文件索引与浏览
   主界面提供统一文件列表，可以按文件类型浏览已导入内容。
3. 关键字搜索与筛选
   支持结合搜索栏和文件类型过滤器查找目标资料。
4. AI 辅助元数据生成
   在设置中配置模型后，可为文件自动生成标签与描述。
5. 主目录与存储规划
   支持配置主存储目录、默认目录与容量限制，便于长期整理资料。
6. 缩略图与元信息提取
   可针对图片、文档、视频等文件生成预览并读取基础元信息。
7. 重复文件检测与状态刷新
   系统具备重复检测能力，并会在文件被外部修改后尝试刷新列表状态。
8. 主题自定义
   支持切换主题模式、主色与背景，方便按个人习惯调整界面风格。

## 2. 推荐使用流程

建议首次使用时按下面顺序完成初始化：

1. 打开设置页，先配置主存储目录。
2. 如需 AI 自动标签与描述，再补充 API Key、模型和 Base URL。
3. 进入导入页，选择本地文件并补全元数据。
4. 回到主列表，按文件类型和关键字检查导入结果。

## 3. 使用手册

### 3.1 文件页

- 这是日常查看和检索资料的主入口。
- 顶部提供“导入文件”和“设置”按钮。
- 页面中部提供文件类型筛选器和搜索框。
- 文件卡片支持打开文件、查看详情以及后续元数据更新。

配图：

![主列表页截图](../frontend/public/docs/home-overview.png)

### 3.2 导入页

- 点击“导入文件”进入导入流程。
- 先选择本地文件，再进入元数据填写步骤。
- 导入前可补充标签、描述和关键词，这些内容会直接影响后续搜索效果。

配图：

![导入页截图](../frontend/public/docs/import-workflow.png)

### 3.3 设置页

设置页当前分为四块：

1. 存储目录
   管理主目录、默认目录和路径冲突校验。
2. AI 配置
   配置模型服务，启用自动标签与描述生成。
3. 主题设置
   配置浅色/深色模式、主色与背景图。
4. 文档与关于
   展示软件简介，并提供“查看文档”入口。

配图：

![设置页文档入口截图](../frontend/public/docs/settings-documentation-entry.png)

### 3.4 设置 -> 文档

本次新增了内置文档页，入口位于：

`设置 -> 文档与关于 -> 查看文档`

该文档页属于前端静态资源的一部分，构建后会进入 `frontend/dist`，再由 Wails 在 `main.go` 中通过 `embed` 打包进桌面程序。因此，只要重新构建桌面应用，最终生成的 exe 就会自带这份文档，无需依赖外部说明文件。

## 4. 使用建议

1. 主目录尽量放在稳定路径下，避免频繁迁移。
2. 导入时统一标签命名规则，后续搜索会更准。
3. AI 功能建议先用少量文件试跑，再全面开启。
4. 如果资料较多，优先维护描述、标签和关键词的质量。
