# LocalSpace 分阶段开发方案

## 项目概述

**项目名称**: LocalSpace - 本地文件索引软件

**技术栈**:
- 后端: Golang
- 前端: Vue 3
- 数据库: SQLite
- 桌面框架: Wails
- AI 框架: eino

**核心功能**:
- 文件导入（支持 AI 拓展标签和描述）
- 文件展示（响应式列表，2-5列）
- 文件搜索（文件名、标签、描述，模糊匹配）
- 文件打开（默认程序）
- 主题切换（颜色 + 背景）
- 多目录管理

#### 9.1 缩略图生成

```go
package utils

import (
    "image"
    "image/jpeg"
    "os"
    "path/filepath"
    "github.com/disintegration/imaging"
)

func GenerateThumbnail(filePath, outputPath string, width, height int) error {
    src, err := imaging.Open(filePath)
    if err != nil {
        return err
    }

    dst := imaging.Thumbnail(src, width, height, imaging.Lanczos)

    if err := os.MkdirAll(filepath.Dir(outputPath), 0755); err != nil {
        return err
    }

    return imaging.Save(dst, outputPath)
}

func GenerateVideoThumbnail(filePath, outputPath string, width, height int) error {
    // 使用 ffmpeg 生成视频缩略图
    cmd := exec.Command("ffmpeg", "-i", filePath, "-ss", "00:00:01",
        "-vframes", "1", "-vf", fmt.Sprintf("scale=%d:%d", width, height),
        outputPath)

    return cmd.Run()
}
```

#### 9.2 缩略图缓存

**文件**: `app/services/thumbnail_service.go`
```go
package services

type ThumbnailService struct {
    cacheDir string
}

func NewThumbnailService(cacheDir string) *ThumbnailService {
    return &ThumbnailService{cacheDir: cacheDir}
}

func (s *ThumbnailService) GetThumbnail(filePath, fileType string) (string, error) {
    cacheKey := s.generateCacheKey(filePath)
    cachePath := filepath.Join(s.cacheDir, cacheKey)

    if _, err := os.Stat(cachePath); err == nil {
        return cachePath, nil
    }

    if err := s.generateThumbnail(filePath, fileType, cachePath); err != nil {
        return "", err
    }

    return cachePath, nil
}

func (s *ThumbnailService) generateThumbnail(filePath, fileType, outputPath string) error {
    switch fileType {
    case "image":
        return utils.GenerateThumbnail(filePath, outputPath, 300, 300)
    case "video":
        return utils.GenerateVideoThumbnail(filePath, outputPath, 300, 300)
    default:
        return fmt.Errorf("unsupported file type")
    }
}
```
