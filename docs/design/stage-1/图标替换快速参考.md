# LocalSpace 图标替换快速参考

## 🎯 最少需要替换的文件

### 必需文件（⭐⭐⭐）
1. **`build/appicon.png`** - Wails 源图标
2. **`frontend/public/logo.png`** - 应用内 Logo
3. **`frontend/public/favicon.ico`** - 浏览器标签图标
4. **`frontend/index.html`** - 添加 favicon 引用

## 🚀 最快替换方法

### 三步替换法

```bash
# 步骤1: 替换Wails源图标
cp 你的图标.png build/appicon.png

# 步骤2: 创建前端图标
mkdir -p frontend/public
cp 你的图标_128x128.png frontend/public/logo.png
cp 你的图标_32x32.ico frontend/public/favicon.ico

# 步骤3: 更新HTML并重新构建
# 在 frontend/index.html 的 <head> 中添加:
# <link rel="icon" type="image/x-icon" href="/favicon.ico">
wails build -clean
```

## 🛠️ 自动化工具

### 使用替换脚本
```bash
python replace_icon.py 你的图标.png
```

### 脚本功能
- ✅ 自动替换所有图标文件
- ✅ 生成多种尺寸的图标
- ✅ 更新 HTML 文件
- ✅ 可选重新构建应用

## 📐 图标尺寸规范

| 图标类型 | 推荐尺寸 | 文件名 | 用途 |
|---------|----------|--------|------|
| 源图标 | 1024×1024 | appicon.png | Wails 构建 |
| 应用 Logo | 256×256 | logo.png | 应用内显示 |
| Favicon | 32×32 | favicon.ico | 标签页图标 |
| Windows 图标 | 多尺寸 | icon.ico | 应用图标 |


## ⚡ 快速命令参考

## 🆘 常见问题速查

### 图标未更新
- 检查是否替换了 `build/appicon.png`
- 使用 `wails build -clean` 重新构建
- 清除浏览器缓存

### 图标模糊
- 使用更高分辨率的源图标
- 确保 ICO 包含多种尺寸
- 检查设计是否适合小尺寸

### 透明背景问题
- 确保PNG使用RGBA模式
- 确保ICO格式支持透明
- 使用专业转换工具

## 📞 工具推荐

### 在线转换
- https://icoconvert.com/
- https://convertico.com/

### 命令行工具
```bash
# ImageMagick
convert input.png -define icon:auto-resize=256,128,64,48,32,16 output.ico

# Pillow (Python)
python -c "from PIL import Image; Image.open('input.png').save('output.ico', format='ICO', sizes=[(256,256), (128,128), (64,64), (48,48), (32,32), (16,16)])"
```
