## 配置流程

### 存储目录配置
```
用户进入设置 → 点击存储目录 → 查看现有目录 → 添加/删除/启用目录 → 保存配置
```

### AI 配置
```
用户进入设置 → 点击 AI 配置 → 启用 AI → 填写配置信息 → 测试连接 → 保存配置
```

### 主题配置
```
用户进入设置 → 点击主题设置 → 选择模式 → 选择颜色 → [可选] 设置背景 → 实时预览 → 完成
```
