# LocalSpace 图标替换指南

## 📋 需要替换的文件清单

### 1. 打包后应用图标（外部图标）

#### 主要图标文件
- **`build/appicon.png`** (最重要) ⭐
  - Wails 使用的源图标
  - 会自动转换为各种格式和尺寸
  - 建议尺寸: 512×512 或 1024×1024
  - 建议格式: PNG（支持透明背景）

#### Windows 应用图标
- **`build/windows/icon.ico`**
  - Windows 应用程序图标
  - 包含多个尺寸的ICO文件
  - 可选（如果appicon.png存在会自动生成）

- **`build/bin/windows/icon.ico`**
  - 打包后的应用图标
  - 可选（如果appicon.png存在会自动生成）

### 2. 内部应用图标（应用内显示）

#### 浏览器标签页图标
- **`frontend/public/favicon.ico`** (需要创建)
  - 浏览器标签页显示的图标
  - 建议尺寸: 32×32 或 48×48
  - 格式: ICO

#### 应用内Logo
- **`frontend/public/logo.png`** (需要创建)
  - 应用内部显示的Logo
  - 建议尺寸: 128×128 或 256×256
  - 格式: PNG（支持透明背景）

#### HTML 头部引用
- **`frontend/index.html`**
  - 需要添加 favicon 引用

## 🔄 替换步骤

### 步骤1: 准备你的PNG图标

确保你的PNG图标符合以下要求：
- ✅ 尺寸建议: 512×512 或更大
- ✅ 格式: PNG（支持透明背景）
- ✅ 设计: 简洁明了，适合小尺寸显示
- ✅ 背景: 透明或纯色（建议透明）

### 步骤2: 替换主要图标文件

```bash
# 1. 替换 Wails 源图标（最重要）
cp 你的图标.png build/appicon.png

# 2. 替换 Windows 图标（可选）
cp 你的图标.ico build/windows/icon.ico

# 3. 替换打包后的图标（可选）
cp 你的图标.ico build/bin/windows/icon.ico
```

### 步骤3: 创建内部应用图标

```bash
# 1. 创建 public 目录（如果不存在）
mkdir -p frontend/public

# 2. 复制不同尺寸的图标
cp 你的图标_128x128.png frontend/public/logo.png
cp 你的图标_32x32.ico frontend/public/favicon.ico
```

### 步骤4: 更新 HTML 文件

在 `frontend/index.html` 中添加 favicon 引用：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>LocalSpace - 本地文件索引</title>

    <!-- 添加这一行 -->
    <link rel="icon" type="image/x-icon" href="/favicon.ico">

    <!-- 或者使用 PNG 格式 -->
    <!-- <link rel="icon" type="image/png" href="/logo.png"> -->
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>
```

### 步骤5: 重新构建应用

```bash
# 清理并重新构建
wails build -clean
```

## 🛠️ 工具推荐

### PNG 转 ICO 工具

如果只有PNG文件，可以使用以下工具转换为ICO：

#### 在线工具
- **ICO Converter**: https://icoconvert.com/
- **ConvertICO**: https://convertico.com/

#### 命令行工具
```bash
# 使用 ImageMagick
convert your_icon.png -define icon:auto-resize=256,128,96,64,48,32,16 your_icon.ico

# 使用 Pillow (Python)
python -c "
from PIL import Image
img = Image.open('your_icon.png')
img.save('your_icon.ico', format='ICO', sizes=[(256,256), (128,128), (64,64), (48,48), (32,32), (16,16)])
"
```

## 📐 图标尺寸建议

### 应用图标（外部）
- **源文件**: 1024×1024 或 512×512
- **Windows ICO**: 包含 256×256, 128×128, 64×64, 48×48, 32×32, 16×16

### 应用内图标
- **Logo**: 256×256 或 128×128
- **Favicon**: 32×32 或 48×48
- **小图标**: 16×16, 24×24

## ⚠️ 注意事项

1. **透明背景**: PNG 支持透明背景，ICO 也支持透明
2. **颜色模式**: 使用 RGB 或 RGBA 颜色模式
3. **文件大小**: 图标文件不宜过大，建议控制在 100KB 以内
4. **视觉测试**: 在不同尺寸下测试图标显示效果
5. **备份原文件**: 替换前备份原始图标文件

## 🎨 设计建议

### 简洁原则
- 避免过多细节
- 使用清晰的形状
- 确保小尺寸下可识别

### 色彩搭配
- 使用品牌色系
- 确保对比度足够
- 考虑浅色/深色背景

### 视觉层次
- 主要元素突出
- 次要元素简洁
- 整体平衡协调

## 🆘 常见问题

### Q: 为什么图标没有更新？
A:
1. 确保替换了 `build/appicon.png`
2. 使用 `wails build -clean` 重新构建
3. 清除浏览器缓存（针对内部图标）

### Q: 图标显示模糊怎么办？
A:
1. 使用更高分辨率的源图标
2. 确保ICO包含多种尺寸
3. 检查图标设计是否适合小尺寸

### Q: 透明背景变成了黑色？
A:
1. 确保PNG使用RGBA模式
2. 确保ICO格式支持透明
3. 使用专业的图标转换工具

### Q: 如何批量生成不同尺寸的图标？
A: 使用前面提到的工具或脚本：
```bash
# 使用 generate_icon.py 脚本
python generate_icon.py
```
